# Snip Frontend

React frontend for the Snip URL shortener.

## Features
- Login and Register pages
- JWT authentication
- Shorten URLs after login
- Copy short link to clipboard
- Logout

## Tech Stack
- React + Vite
- Fetch API for backend communication

## Run Locally
```bash
git clone <repo>
cd frontend
npm install
npm run dev
```

Runs on `http://localhost:5173`

## Backend
Requires the Snip backend running on `http://localhost:8080`
→ https://github.com/serilevanjalines/Snip
